# Shared Item Display Mockup Prompts

Reference: `design/refs/emulator-current.png`. Source of truth:
`design/briefs/item-display.md`.

## Variant F — Grouped affix ledger

Produce a close component study of the populated Vaal Regalia item panel inside
the existing poecraft dark UI. Preserve explicit Prefixes and Suffixes groups,
but replace oversized cards with compact ledger rows. Make P/S side, T1/T2/T3,
family name, exact stat lines, classification tags, crafted/fractured markers,
empty-slot state, rarity, Shaper influence, base name, item level, and affix
count immediately readable.

## Variant G — Unified six-slot item

Produce the same populated Vaal Regalia as one compact six-slot list labelled
P1, P2, P3, S1, S2, S3. Stat text is primary; tier, family, tags, and special
state are secondary but visible. Do not use large Prefix/Suffix section cards.
The layout must fit a 300–380 px side rail without horizontal scrolling.

## Variant H — Responsive split columns

Produce the same populated item in a wider Emulator panel with Prefixes and
Suffixes as two balanced columns of three stable slots. Each row shows tier,
family, exact stat text, tags, and state cleanly. The visual language must have
an obvious stacked narrow fallback for Calculator, even though the mock shows
the wide state.
