## Primary research

**P1. Johannes Schmalz and Felipe Trevizan.** *Efficient Constraint Generation for Stochastic Shortest Path Problems*, accepted Artificial Intelligence, 2026, DOI10.1016/j.artint.2026.104505. [Author page](https://schmalz.cc/cgilao/), [manuscript](https://schmlz.github.io/downloads/cgilao/cgilao_aij26_paper.pdf). Reviewed abstract, initial algorithm motivation and finite-SSP/properness/cost/tie assumptions; not all proofs/experiments or diagrams. The updated manuscript supersedes earlier versions according to the author page. It motivates measuring avoidable action computation, not importing benchmark speedups or a new solver. No native correspondence or novelty claim follows automatically.

Documentation notes process creation can be uninterruptible on platform APIs. The repository has its own deadline and cleanup owner, which must be inspected directly; the docs do not explain which component caused the hosted1.891s supervisor interval.

External sources were consulted for research/verification, not game mechanics. Mathematical first-exit/grouping arguments are conditional reasoning preserved in the packet, not a claim of unprecedented algorithms.
