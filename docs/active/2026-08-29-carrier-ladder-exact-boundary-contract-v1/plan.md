## Objective

Add the smallest bounded observational seam that can turn one existing
ladder/joint-assembly missing-frontier record into a reproducible exact
boundary contract.

The seam must retain the failed coarse selected-policy prefix before ordinary
restore, replay only that prefix from the authored exact start through
engine-owned strict kernels, and enumerate every reached exact item that maps
to the named missing coarse parent without representative substitution or
projection merging. It must also name a typed rejoin/exit contract from
existing goal and independently executable frontier authority.

This boundary does **not** search for, verify, compose, publish, or store a
fragment. It creates the prerequisite entry/exit witness only. Ordinary solve
work, ordering, bounds, incumbents, compilation, and artifacts remain the
control authority and must be identical with observation disabled or enabled.

## Locked Authority And Scope

1. Existing joint assembly alone identifies the failed candidate and missing
   coarse parent. Observation may not invent or reprioritize obligations.
2. The retained prefix is immutable and identity-bound. It may not become an
   incumbent, fallback, Bellman boundary value, proof lower, action-envelope
   retirement fact, or scheduler input.
3. Exact recovery starts only from the request's authored
   `pc_item_state`. Every transition comes from existing strict native
   primitive/fixed-option kernel authority.
4. Every reached exact member mapping to the boundary is retained distinctly
   by collision-checked stable key and complete hard item state. No
   representative, sample, projection merge, or renormalization is allowed.
5. The typed exit contract may name only:
   - exact terminal success under the current goal; or
   - a coarse parent/operator continuation already owned by an independently
     executable ordinary incumbent/frontier in the same complete identities.
   It may not promise that private continuation search can reach an exit.
6. Product defaults remain off. The initial setting is benchmark-private and
   versioned. No public C ABI, strategy operation/condition vocabulary,
   mechanic, action kind, canonical data, GUI, or product-default change is
   authorized.
7. New observational storage and strict replay work require explicit state,
   transition, row, work, byte, wall-time, and sample caps. They must yield
   cooperatively, honor cancellation, and refuse truthfully.
8. Observation-on runs must account private work separately. Ordinary
   deterministic work, order, bounds, stop, policy, compiled strategy, and
   exact-evaluation result must remain identical to observation-off controls.
9. Common native source or telemetry serialization changes require the
   complete downstream native/release-WASM/web checks from the change-impact
   map, even though the setting remains disabled by default.
10. The preserved untracked file `0` is user state. Do not read, alter,
    stage, clean, rename, or commit it. Stop if any other unexpected dirty
    path appears.
