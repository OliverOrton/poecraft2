## Economic witness before live scheduling

A saved-donor candidate can qualify its full graph and actual cost. It does not
prove live headroom, timely service or current-run discovery. Report whole query,
local construction, tail certification, compilation, checking and retained costs,
including failures. The six-check witness cap does not exempt incomplete work from
accounting. Do not use node expected-cost annotations as acceptance values.

A material goal is C_new <= 0.8 * C_strongest_compatible_unattended. Any smaller
strict improvement is still reported; default retention must weigh its real
construction/check cost and effect on other progress. No comparison to an
artificially worsened baseline, changed prices/start or wider capacity.

precise event clocks.

## Proportional final acceptance

Every changed returned graph needs independent full-root native evaluation. No
Simulator for unchanged controllers. Use the current approved1000 trials only if
fresh changed-controller execution qualification actually needs them; retain all
censorings. Target affected C++ tests, web/protocol layers and source-matched worker
controls rather than repeating broad suites per patch.

Record what passes independently: source coverage, complete candidate semantics,
original-cost improvement, live capacity, product activation, no-new first-policy
regression, numerical correctness and full-scope exactness (which remains open
unless separately established). Remove unused experimental runtime scaffolding on
a negative; preserve compact native witness/cost evidence and the conditional math.
