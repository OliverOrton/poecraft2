## 2. Where the preceding plan was too restrictive

The prior prompt deliberately confined the query to Exalt/Annul/Scour and a
clean goal-only Rare item with exactly one missing requirement. Codex stopped
correctly when neither donor contained an eligible entry. [R18]

That tested one family's initiation set. It did not test generic post-incumbent
improvement, a native Eldritch continuation, dirty capacity repair, or replacement
of an entire compiler-authored macro decision. The old clean-compiler shortcut
needs those restrictions. Their failure does not mean every broader candidate
would be unsafe. It means that shortcut is not the right constructor for these
sources. [R5,R6,R8,R10]

The planning error would be to reuse the same eligibility as a prerequisite for
all future work, or to waive it without replacing its proof obligations. This
programme separates semantic safety from a particular recipe's convenience.

## 4. Existing native machinery to reuse

The native entry interface accepts compiler-defined decision requests and keeps
exact item/control identity, the true global router's destination, hidden-context
status, independently evaluated continuation and scope. It does not define
Exalt/Annul/Scour as the universal decision set. [R8]

`StrategyPolicySelectedKernel` describes a complete selected planner-operation
macro. It retains mandatory internal operations, routes, checkpoints and observed
choices, and stops at a next genuine global decision or goal. This is existing
upper-side evidence, not permission to interrupt an option or assume an alternate
macro has the same law. Inspect its actual requesting path and limitations before
using it; a type declaration alone does not establish cheap universal support.
[R8]

The general dirty-continuation compiler already composes a complete local domain
with the old controller at global decision routers. The narrow clean single-pass
optimization is separate and cannot be enabled for dirty entries by deleting its
assertions. [R10,R11]

An earlier retained first-return improvement also already certified previously
uncovered physical tails via the old controller and paid a complete Annul bridge.
Missing source-snapshot coverage did not imply physically unroutable continuation.
This is established machinery, not a new root Exalt campaign to repeat. [R12]

## 5. Selected direction

Select a native-context repair at an actual positive-occupancy compiler decision.
Prefer the existing A5 donor; examine A4 only as the one named contrast or control.
The first candidate can be a dirty-entry repair or an Eldritch-context repair,
but only when the actual native descriptors, complete laws and global boundaries
support it. Preserve all native final-goal semantics.

The initial candidate family compares one complete planner action, and when
necessary one complementary second decision, with handing off to the verified
base. Setup may be worthwhile only together with the action it enables. Keep
existing singleton choices and the base fallback. Do not restrict consideration
to options that increase goal count immediately.

There is no promise of a cheaper controller. The deliverable is a supported,
fully evaluated economic experiment at a real source rather than another query
that first requires the absent clean shape. Complete alternatives that are more
expensive are useful economic negatives; incomplete/refused ones remain distinct.

## 6. Research posture and limits

Options/SMDPs distinguish an option's allowed starting states, its internal
policy and its stopping boundary. The existing clean family has one narrow
starting set. A new context-specific family needs a new native contract, not a
reinterpretation of the old one's result. [P1]

Rollout and multistep policy improvement supply precedent for a small search
followed by a known policy. We do not import approximate aggregation, a discounted
convergence result, or a promise of improvement from arbitrary native estimates.
The packet gives its own finite, fully specified argument and leaves actual
native correspondence and publication to the existing checker. [P2]

Conditional mathematics is already preserved in canonical `policies.md`, including
dirty intermediate states, complete first-exit laws, root correspondence and the
failure of locally proper fragments to establish global properness. This programme
should extend those sections with actual implementation, not duplicate them. [R11]
