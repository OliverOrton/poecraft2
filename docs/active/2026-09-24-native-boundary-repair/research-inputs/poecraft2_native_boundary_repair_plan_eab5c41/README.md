## Non-negotiable distinctions

- A selector calling an operation unsupported does not prove the native engine
  cannot execute it.
- Dirtiness at an intermediate decision is not failure of the native clean goal.
- A real whole-program decision may be replaceable; its mandatory interior is not.
- A bounded construction horizon is not a hard user crafting-action limit.
- A saved-graph witness is not ordinary discovery, and standalone checker memory
  is not extra live-solver headroom.
- A correct local expectation is not the cost/properness of its recurring root
  composition. The complete native emitted controller decides acceptance.

All source is inspected read-only. The scripts in this packet do not implement or
simulate PoE mechanics. No repository edit, new native solve, WASM build or
Simulator qualification was performed in this review.
