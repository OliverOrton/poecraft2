# P0–P9: sustained implementation plan

## Programme contract

This is an authorized multi-checkpoint implementation design, not a request to produce another plan after P0. Continue sequentially through P0–P9, retaining coherent tested increments. The expected work is multiple substantial coding/testing sessions; no minimum elapsed duration, artificial soak or fabricated hour estimate is a success criterion. Use checkpoint handoffs if the client ends a session. Resume the same programme rather than inventing a successor.

The two primary outcomes are (1) an operating bounded Current L/R diagnostic that cannot consume clean proof accidentally, and (2) a better-founded selective-retention candidate family with actual Finder and Current consumers. Economic superiority is measured, not assumed. Mandatory correctness conditions are gates; arbitrary percentage targets do not justify deleting sound useful engineering.
