## External verification

[Official Codex configuration reference](https://developers.openai.com/codex/config-reference/) redirects to [ChatGPT Learn configuration reference](https://learn.chatgpt.com/docs/config-file/config-reference). Read September12,2026. It documents `background_terminal_max_timeout` as the maximum empty-input `write_stdin` wait in milliseconds, default300000. It does not establish installed client support, automatic task notification or any billing saving.

The prior literature/34-check research files are preserved byte-for-byte under supporting/. This turn revisited current native evidence and the official waiting setting; it did not repeat the prior whole literature search. The new occupancy/action-availability notes are direct finite-system derivations with stated assumptions, not novelty claims.

## Not done by this review

No repository write, commit, push, build, native solve, native test suite, simulator, local Codex-log access or host-RAM inspection. The arithmetic scripts are synthetic and package-only. The reported original/private controls and native values come from the pinned implementation record; causal generalization beyond that record remains for the next experiments.
