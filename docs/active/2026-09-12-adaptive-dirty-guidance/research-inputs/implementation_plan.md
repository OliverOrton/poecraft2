## 5. M3 — The actual adaptive-estimate experiment

This is now selected, not another deferred future note. Implement one small native run-local guide at a consequential **preconstruction or next-obligation** decision. Do not wrap the existing exact private policy iterator with an unused score.

### Separate numbers and targets

- Certified completion lower: proof/pruning only under its original contract.
- Private fixed-controller or restricted-model value: a useful estimate for that specific domain/controller, not full-scope V* or a portable entry certificate.
- Adaptive completion estimate: ordering/proposal information allowed to be wrong and change in either direction.
- Computational effort prediction: construction/check cost and censoring, kept separate from crafting cost.
- Verified graph/entry cost: upper authority only for the actual validated entry and decisions.

Do not mix these in a shared values vector consumed as executable frontiers. A typed distinction or an existing suitably explicit owner suffices; do not create a new proof framework.

### Start with existing estimates and small residual correction

Use existing native private values, complete row expectations and short sparse cyclic lookahead. Unknown tails may receive an explicitly approximate predictor only in the guidance view. For observed choices, preserve the native timing of the choice; for a committed program, retain its full decision sequence. Do not use best successor instead of expectation or unroll a million retries one step at a time.

A suitable first adaptation is a small regularized, damped feature-bucket residual correction to the frozen base predictor. Features can include goal/side distribution, occupancy, capacity, relevant blocker/protection context, native price/pool summaries, action family and candidate stage. Do not encode case/base IDs as learned answers or force every extra modifier to have positive marginal cost. Reuse features and maintain a small accounted table with deterministic bounds.

Update only on new complete native row batches or independently completed candidate/entry evaluations. Preserve the estimate version used for the prediction. A same-controller, same-entry native check can calibrate a private prediction; a different composed root cannot label that earlier local value. A restricted completed-action minimum is a pseudo-target, not ground-truth V*. Do not train the optimum to equal the current expensive fallback.

Timeouts, cap hits, missing routes and censored action-limit trials update effort/coverage knowledge, not 'infinite craft cost' or 'zero tail'. Sparse observations need shrinkage/backoff; no universal calibration guarantee is assumed. Static S still receives ordinary newly completed native evidence; it disables the learned residual/trust update, not all numerical progress.
