# Native Solver Lab Case Authoring

**Status: active implementation boundary.** Oliver selected this boundary on
2026-08-28 after exercising Native Solver Lab v0.

Parent: [Active work](../README.md)

The Lab currently runs five frozen research cases well, but it cannot create
or revise local cases. This boundary adds a revision-safe authoring bridge from
the browser Calculator to the native Lab, exposes the same lifecycle through
GUI, CLI, and the closed MCP adapter, and configures the repository-local MCP
server for Codex.

Execution authority is the accompanying [plan](plan.md). Results and evidence
will be recorded here before the boundary is archived.
