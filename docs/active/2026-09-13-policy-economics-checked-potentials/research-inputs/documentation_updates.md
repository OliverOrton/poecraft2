## docs/solver/mathematics/lower-bounds.md — candidate potentials and checked repair

A useful value estimate need not already be a lower. It can propose a finite potential for a current complete lower model. If a feasible base l and fixed-boundary direction d are given, a line candidate h=l+alpha*d must satisfy every original model constraint. For an ordinary affine row define b=c+P*l-l(s) and a=d(s)-P*d. An increasing candidate requires alpha*a<=b; a positive a supplies a limiting ratio b/a. Scalar residual families and actual observed choices remain in the cover. Changing value-dependent minimizers must be recomputed at the final vector. The retained exact checker, followed by the producer's native correspondence, owns any accepted bound.

This is not unrestricted scaling by a heuristic safety factor. A previously valid native bound may not be feasible in a newly weaker model. A blocking ratio limits the selected direction only; a proper auxiliary-policy witness is needed to establish a ceiling for the whole optimistic model. Neither ceiling is the native optimum. A checked local value needs an actual same-scope consumer before it changes the displayed root lower or retires an action.
