## Programme and target interactions to test

The same programme vocabulary does not imply identical physical stopped kernels. R may make a native goal-bound option terminate earlier. That is a target-dependent programme effect, not an arithmetic error or permission to skip mandatory cleanup inside an already chosen concrete execution programme.

The original compiled graph's stopping edges are authoritative for execution. If the target is met inside a mandatory macro but the graph has not yet reached a permitted decision/exit, do not magically absorb the process. Compile a different legal programme only where native semantics permit it.

R accepting an extra affix does not make its identity irrelevant to later actions **before success**. Preserve blockers, crafted/fractured traits, influence and Eldritch/control context until the exact native programme or routing no longer observes them.
