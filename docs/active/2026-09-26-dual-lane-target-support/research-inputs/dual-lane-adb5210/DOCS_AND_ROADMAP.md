## Next choices after U5, not authorized automatically

### A. Same-clean policy quality

If the existing Finder remains dominated by paid Chaos recovery, use its actual complete loss/return statistics to propose a bounded retention/completion family. Current's parallel question is whether that family already has complete native rows and routed tails but lacks service or composition. One shared native programme representation can feed the two consumers, but their ordering/acceptance remains independent.

A new family first needs a complete original-root economic witness. No use of a coverage graph or free partial item as a clean upper. Avoid the previously inactive S and negative O treatments unless a genuinely new profile yields a new causal premise.

### B. Coverage-target exact proof

If the target-neutral R search is materially easier, decide whether to retarget one existing positive lower producer and its complete action/member domain. Use the newly established original-target checker and experiment identities. A zero-profile closure-unavailable outcome does not settle how a fully qualified R exact prover performs.

Select a current optimistic-model limitation, not arbitrary additional sweeps. Any candidate computed for R must have the correct terminal boundary and be checked at all predecessor inequalities; zeroing only newly terminal states is not a repair.

### C. Goal product migration

Make a separate versioned decision about new authored goals, extras defaults and explicit open-slot/count controls. Existing v1 goals remain clean; older coverage-era raw requests need provenance. Imported compiled strategies carry effective conditions and must not be silently rewritten. The U programme does not authorize public migration merely because native diagnostics pass.

### D. Finder-to-Current incumbent handoff

Only useful if a Finder controller actually improves Current for the same target/context or solves a case Current cannot supply. Import a checked graph plus compatible context and evaluation, not a role feature/value or learned lower. Budgets include discovery and checking; no free offline seed in a same-budget comparison. The current inferior A5 Finder is not a reason to build a hybrid scheduler now.
