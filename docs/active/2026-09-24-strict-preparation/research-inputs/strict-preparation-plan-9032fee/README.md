## Decision

Do not repeat the closed D0–D4 role census or install a general symmetry template.
Measure and repair **one actual repeated operation in strict-policy preparation**:
observation input construction, backward requirement propagation, requirement/
partition-key preparation, or their accounting. Current source exposes concrete
sharing and repeated-scan seams. Their runtime contribution is not yet measured.

This keeps the useful part of Oliver's intuition—share invariant reasoning while
keeping each physical instance and its answer—without requiring weights, policies,
or state values to become interchangeable. An exact metadata/dataflow reuse result
is not a demonstration of a broad heterogeneous policy quotient.

The larger native preparation interval is the target, not a fabricated 50-second
saving. Its counter is an elapsed prefix of a persistent session and includes
initialization and later partition-node preparation. The previous per-locator
trace does not cover it completely.
