## What is already established

H0's effective-success repair, zero-cost completed-root path and graph move are retained. H1/H2 now support finite conditional controllers and native Scour→Alchemy; they still do not implement the requested protected progress-retaining family. These are engineering gains, not competitive finder economics. Current remains default.

The terminal-debt tie in the handoff is mathematically correct under its assumptions. But Current already ranks satisfied-goal subsets before within-subset unrelated occupancy, and its focused legacy mode does not perform that cleanliness sort. The debt is a narrowly activated initial-row preference, not a state-value function. Its known counterexample is already in canonical mathematics.

## Deliverable

Coverage/timing diagnostics remain separate outcomes. A positive local cleanup route alone is not a full-root saving.
