## 3. Important corrections to the broad causal story

### Current does not give a dirty three-goal carrier the empty carrier's global priority

Carrier buckets are indexed by complete satisfied-goal mask. Subset order starts with larger satisfied counts; the scheduler then round-robins masks. Within an IncrementalLegacy mask, fracture/protection precede unrelated occupancy, and stable state identity breaks the final tie. [R05–R06]

This can still delay a valuable dirty member **within the same mask**. It does not numerically cancel its three acquired goals against an empty carrier in this scheduler. Round-robin fairness also means a lower-progress mask can receive service before every higher-progress member; that is a separate deliberate scheduling choice.

FocusedLegacy does not run the within-mask cleanliness sort; it preserves its numeric-priority input order and separate class quotas. [R05,R07] A patch to the shared comparator cannot be credited with changing a path that skips that comparator.

The alternative obstruction-aware/cooperative profile exists but is disabled. Its historical multi-change qualification failed several controls [R09]. Do not enable it wholesale or claim obstruction features are missing. A narrowly isolated current test remains possible; the old result is not a proof against every new tie rule.

### Finder does not use Current's terminal-debt function

Its cheap score still uses prices, goal count and renewal/recovery flags. The more concrete bias is in the generated programme [R10–R12]: if slot 0 is present and total explicit count is 4/5/6, attempt Annul; otherwise reroll with Chaos. A deeper child tests slot 1 and can run Scour→Alchemy, which resets rather than protects progress. These are candidate-language/control choices, not just a priority score. Equal role-feature naming does not make them equivalent to Current's heuristics.

This gives a useful branch if Current ordering is not the bottleneck: construct one actual progress-retaining native continuation. Do not call changing the candidate grammar an ordering-only result.

## 4. Recommended next question

Find an actual dirty carrier or complete selected row for which:

1. the current source mechanism really applies;
2. a different decision is both representable and worth exploring;
3. current service or candidate construction loses that opportunity;
4. a complete original-root controller establishes useful economics under the original budget.

There are two distinct evidence channels: **search work/service history** and **crafting-policy first-acquisition cost**. They inform each other but do not substitute for each other. A large cleanup tail can be unavoidable; a small tail can coexist with costly loss of partial progress before all goals are ever held.

The next package therefore begins with bounded attribution and a stopped-policy diagnostic, then chooses one treatment. It does not immediately implement a new scalar, relax the goal, or resume generic finder expansion.
