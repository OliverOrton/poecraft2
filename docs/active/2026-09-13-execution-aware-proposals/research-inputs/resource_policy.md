Keep the input, artifact, prices, scope, native mode, executable, candidate limits, sample controls and worker configuration explicit. Do not waive strict identity exclusions or rewrite old raw results.

The user's permission for useful additional compute remains in force. A selected candidate may use a separately identified 900/1140/1170-second time profile, a larger cumulative work limit, or a higher specific state/memory limit when the current stop explains why a promising calculation cannot finish. A 16-GiB aggregate/8-GiB checker/28-GiB host reservation is conditional on actual available physical AND commit headroom; earlier machines did not always admit it. No simultaneous wide solves without a separate concurrency experiment.

Do not raise memory to repair an invalid native continuation. Do not raise time for a fully evaluated expensive controller. Record old/current allowance, debit before the candidate, candidate debit and remaining work. Every child/checker continues charging the shared owner; extra fields are not extra unaccounted RAM.

## Three comparison arms

B uses reviewed d2 code at the declared research profile and comparable activation. E adds bottleneck-entry/candidate coverage with cost-only ordering. T has the same opportunity and checking machinery with count-aware proposals. Use the better compatible high-water result to constrain targets even if a new timed baseline misses it. Report capacity-enabled changes separately from E/B code gains or T/E guidance gains.

A few cheap fixed-policy/native entry queries may precede the timed batch. Do not rerun the whole corpus to rediscover retained counts. Independent B/E/T requests can be executed serially inside one deterministic batch; dependent decisions start the next batch. Long waits are an existing working capability. No routine 30-second model polling, duplicate workers, monitor LLM, new dashboard or mandatory observation ceremony.

Native owned bytes, checker peaks, process working-set snapshots and actual RSS peaks are different quantities. C and N concern crafting execution, not solver seconds or reforge logical work. A smaller candidate graph does not prove its independent physical evaluation is smaller. The actual active owner must determine any further resource change.
