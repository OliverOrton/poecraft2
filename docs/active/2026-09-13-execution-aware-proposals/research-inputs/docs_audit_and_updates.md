## 3. Authored insertion: policies.md, beside fixed-policy reward/occupancy

### Primitive execution count is a separate reward

Fix the same complete, proper finite controller and its transient nonterminal matrix P. Let c be expected native monetary cost per represented decision and n the expected number of primitive executions before that decision's exit. Then

    C = c + P C,       N = n + P N.

The same transient operator gives C=(I-P)^(-1)c and N=(I-P)^(-1)n. An option can execute many primitives; its n must follow the native expected internal-action reward and the same first-exit/retry normalization as its successor law. One option invocation, one graph traversal and one unit of currency are not equivalent counts. Native OptionKernel already exposes expected_primitive_actions. Final physical evaluation owns a published controller's actual count, just as it owns its complete cost under the existing numerical contract.

At entry s, d^T=e_s^T(I-P)^(-1) gives C(s)=d^T c and N(s)=d^T n. These immediate contributions may be aggregated by action or compatible native region. Continuation values and continuation counts already include future work; summing them as separate contributions double-counts overlapping tails.

Properness and structure do not bound execution length tightly. A one-state retry with success probability p has expected count 1/p. Long expected execution is an important economic/practical signal, not proof that a shorter allowed controller exists. Nor does the mean alone determine finite-limit completion. Keep native expected totals distinct from truncated samples and preserve all capped trials in the denominator.

This is an application of the existing fixed-policy reward and stopped-program arguments (CLM-0002/CLM-0004), not a new unconstrained optimality claim.

## 5. Authored insertion: lower-bounds.md, after heuristic distinctions

### Count guidance is not a monetary lower

An estimate of remaining primitive actions can guide search without being a lower. A certified count potential instead requires complete same-scope inequalities h_N(s) <= n(s,a)+E[h_N(S')] for every required action/member, with the original goal/control semantics. Its units are actions. A monetary lower follows only from an additional valid reward relationship; a current policy's average cost per action supplies no all-action guarantee.

Adding a positive count penalty changes the objective. A checked vector for c+lambda*n does not automatically lower-bound the optimum under c. For example, a cost-0.01 retry with success probability 0.01 has C=1,N=100, while a cost-2 immediate finish has C=2,N=1. At lambda=0.02 the latter has the lower penalized score 2.02, but the original cost optimum is still 1. Estimates and modified rewards cannot remove an original model's optimistic escape or missing action obligation.

## 6. Authored insertion: numerical-closure.md, near residuals

### Execution-count-weighted residual sensitivity

For the same proper finite controller, let r=c+Pv-v. Then C-v=(I-P)^(-1)r. If a justified componentwise bound gives |r_i| <= epsilon*n_i, nonnegativity of the transient inverse yields |C-v| <= epsilon*N. Thus recurrent execution can amplify small local errors. This statement requires the complete same-controller law and the stated bound; it grants no uniform guarantee to a learned estimate and does not loosen any native acceptance tolerance.
