Carrier deferral produced 186 expanded states/2,133 rows rather than 58/447, but no different controller. Releasing comparison storage across carriers did not remove the first refusal. The later terminal-depth/completed-context trial reached the 240-second finish with 186 states/2,497 rows, no cap hit, and only one admitted alternative. It still independently evaluated to the same C149,977.25 graph. Its final memory figures were recorded after release, not at the earlier simultaneous peak. All three treatments were removed. [R2–R3]

That is not proof that memory improvements are useless. It is evidence against automatically equating additional expansion with useful policy coverage in this case. The new direction should propose economically different complete continuations, not keep advancing the same branch merely because more of it now fits.

No runtime, facade or WASM change survives the memory work. The currently qualified ordinary C4 recovery is still the compact transport release. Oliver accepted its measured 2.643-second maximum ordinary call for that policy-quality gain; the old 250-ms target is still a recorded failure, not a reason to reopen all responsiveness work before this pilot. ## 2. User's choice is broader than exact symmetry

The requested primary problem is three required prefix families with potentially different tier counts and weights, tested both alone and with one/two required suffixes. The method must retain those differences. A perfect Fire/Cold/Lightning permutation is a useful control only if native data proves it, not the route's defining eligibility condition.

The relevant shared object is a decision structure: which progress to retain, which role to attempt next, how to open capacity, how to stop after a useful outcome, and how to recover. Each concrete binding still supplies the real native law and economics. Failure of equal coefficients must not stop the whole research programme; it stops only an unjustified exact quotient/value-reuse claim.

## 3. Existing machinery is substantial

`FixedOptionSpec` already carries a side, real action IDs, setup/program IDs, a vector of exit goal slots, an exit threshold and a carrier role. Automatic synthesis already binds many programmes to missing goals and preserved sides. The Eldritch path chooses concrete setup from current dominance and prices. Temporary blockers are grouped by exact blocked eligible pool and goal/followup/side, with cost-sensitive representative choice. [R6–R9]

Complete option kernels are also memoized already. That path checks planner identity, expected resources and the complete native kernel after construction. Renaming a shape key is not a license to reuse its probabilities or continuation values. [R11]

The observed ProtectedRepeat generator emits one missing slot at a time even though the fixed vocabulary can express multiple target slots. That is a **specific candidate-coverage hypothesis**, not proof the whole solver lacks every equivalent multi-goal controller. The baseline inventory must compare actual generated specifications and complete candidate signatures. [R9]

This establishes the pilot's novelty test: it must add cross-role composition/acceptance or avoid repeatedly constructing the same structural decision problem. Merely creating another loop over `goal.slots` is already covered by the baseline.

## 6. Decision

Select a native **role-parametric continuation pilot**, with non-identical parameters retained and reoptimized. Begin with six cheap case/role probes, one existing-machinery delta, and tractable native binding controls. Then implement one bounded family and qualify full root strategies. Keep optional exact symmetry and symbolic numerical response sharing as clearly separate, gated extensions.

Do not reintroduce the memory-only patches, bypass protected-program checks, train a model, build a permanent recipe database, or start a universal quotient/parametric solver in this programme. The [milestones](03_DESIGN_AND_MILESTONES.md) define how to stop with a useful result or a concrete negative rather than indefinitely adding machinery.
