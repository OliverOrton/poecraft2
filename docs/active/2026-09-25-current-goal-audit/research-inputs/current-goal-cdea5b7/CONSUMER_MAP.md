## Proof compatibility decision: required before E3

For each consumed lower or pruning bound, give its theorem/native premise, zero boundary, action/member coverage, scope identity and treatment under L/E/R. The name `clean` alone does not prove invalidity; the actual boundary and relation decide it. Conversely, a friendly generic name is not proof of validity for R.

Preferred route: retarget existing finite proof queries with the new goal classification and freshly check the actual stored vector under the same complete native relations, where the domain already expresses those target states. Preserve the original L/E result and initialisation order. Do not invent a new lower model just for this comparison.

Fallback route: define one **common-safe proof profile**, identical for L/E/R. It consumes only producers whose validity covers the easier coverage target (and therefore the clean target under the stated scope), plus universally sound zero/fallback contributions and genuine compatible completed proof work. Suppress unsupported producer consumption AND any dependent pruning/certification in all arms; account for any retained preparation overhead equally. Explicitly identify this as an algorithm/profile treatment relative to ordinary defaults.

Do not silently apply strong clean lowers in R, clamp them to observed costs, or disable them in R alone and call the timings a pure terminal effect. A cross-target comparison under a common-safe profile answers a useful controlled question, but is not a complete ordinary-default attribution. Report that limitation.

Even with weak initial lowers, exactness is possible only if the existing closure owner actually proves it for the full mode-specific problem. If some proof correspondence remains unimplemented, mark closure **unavailable** for that mode. Distinguish this from **available but not reached under caps**. Do not print a manufactured lower/upper equality.

## Mandatory mutation negatives

A cached clean potential used in coverage mode must refuse; a coverage-terminal with a positive consumed remaining-cost lower must fail validation; a changed predecessor potential must be rechecked; an explicit-clean contract claimed equivalent with a threshold exception must fail; a loose artifact presented as a strict winner must fail original-goal binding.

Mechanical rows without target-dependent stopping may be compared for equality. A goal-normalised macro or gated retry row can legitimately differ between modes. That difference must be disclosed as target-dependent control semantics, not blamed on changed native random mechanics.
