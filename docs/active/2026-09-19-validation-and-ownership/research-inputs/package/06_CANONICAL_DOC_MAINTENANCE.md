## 6.5 Closeout quality checklist

The final record should state what changed, which old mutation paths were removed, which stages deliberately remain mixed or unverified, actual validation outputs, resolved identities, current failed performance gates, and the next decision. It should not say “all tests pass” while a required integration lane is absent, “WASM current” based only on native source, or “ownership complete” while a mutable retained-vector alias remains.

Archive the finished programme by the repository's existing practice only when its continuation state is clear. Keep old evidence and incoming links accessible. Update edited links, relevant claim references and generated views through their existing owners. Do not launch a whole-repository documentation rewrite or duplicate all result narratives into direction, source map and every index.
