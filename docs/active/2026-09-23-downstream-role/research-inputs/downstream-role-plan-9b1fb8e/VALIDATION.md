# Validation and evidence contract

## Identity and control

Pin current source plus dirty patch, native executable, release WASM when used,
runtime data manifest/payload, ordered goals/start, all effective prices/overrides,
action scope, automatic dependencies, native activation, capacities, clock origins
and host load. Use the existing resolver/comparator, not an ad hoc identity hash.
Respect corpus manifest artifact DIRECTORY versus file arguments. A template's
structural key is never the experiment identity.

## Required tests for a retained pilot

- Unequal real bindings with cold-agreeing complete outputs, not just two equal
  synthetic arrays. Include actual ragged-tier/member behavior when relevant.
- A deliberately unequal abstract choice fixture proves the shared structure does
  not lock in the first binding's selected action. Native data are never changed
  to force a reversal.
- Below-tier family occupancy, overlapping requested masks, actual four junk
  categories, crafted/fractured maps and suffix constraints remain distinct.
- Missing mapped action, unsupported observer, altered active support, wrong output
  resource map and changed target/price/scope refuse/rebind rather than reuse stale
  evidence. Explicit terminal and tiny positive-mass trap cases remain covered.
- Changed external port values, unaligned ports, internal/external cyclic return,
  and changed numerical generation do not reuse old bound conclusions.
- Interleaved bindings and cap/eviction/cancel preserve ownership and cumulative
  work. No partial result enters an exact row cache; no extra allocation allowance.
- Repeated passive diagnostic reads do not construct rows, consume work or alter
  selection. Disabled instrumentation remains passive and small; time overhead is
  measured separately from logical passivity. Trace truncation stays visible.
- Exact kernel/value caches remain on in the baseline. An unchanged selected graph
  retains authority; a changed one passes complete original-root independent check.

Use the existing focused native harness selected by the actual changed owner. Inspect
`engine/tests/test_main.cpp` for accepted selectors rather than invent a command.
Examples already present in this codebase include calculator, solve, refinement,
compiler/evaluator, assertion service, return bridge and joint-continuation families;
not all are required for every pilot. First use small explicit native fixtures,
then one realistic binding workload and only the affected original-root comparisons.

A full independent graph evaluator used as a development oracle is not part of a
runtime speed measurement unless the product still needs it at that point. Any
mandatory product compiler/checker cost belongs in all-in measurements. Complete
cold original-root checking remains the publication authority during the pilot.

## Timing and capacity claims

Use identical finite observed binding tasks before/after. Include first-template
cost, warm/cold effects where relevant, match/guard cost, actual coefficients and
output/recheck work. Identify nonoverlapping timer scopes or label inclusive time.
A thousand fabricated identical calls does not represent native recurrence.

A proposed 25% structural /10% relevant all-in gate requires one counterbalanced
confirmation. Also state observed share of full run and time to the same verified
policy. A tiny phase speedup stays a tiny result. A capacity result must account for
concurrent parent/template/binding/compiler/evaluator storage with original caps.
Do not compare selected post-release memory to an old peak.

Economic improvement is measured at the same original request/profile and existing
numeric tolerance. Compare with both the fresh baseline and the strongest compatible
retained reference, not a deliberately weakened baseline. Known ordinary references:
C4 3746.1319409485764; C5 first-policy 85558.70618560436; exact Regalia
65.60036144971359; Ring-two 149977.25092497544 bounded. Wider-profile Bow/Ring-four/
Amulet references are not ordinary product targets.

Rebuild and test source-matched WASM only after relevant native evidence, before a
browser claim. No rendered UI review is implied by component/worker tests. No new
Simulator for unchanged strategies. A genuinely changed controller uses independent
native evaluation and, when required, the owner-approved 1000 execution trials
with all action-cap censorings retained.

## Stop and handoff

A missing premise is not an execution failure to hide; a passing hash does not
prove all cancellation paths. Report actual source/domain, excluded/capped tests,
partial traces, all final graph identities, true CI status and remaining structural
versus numerical versus discovery problems. No push. No automatic successor.
