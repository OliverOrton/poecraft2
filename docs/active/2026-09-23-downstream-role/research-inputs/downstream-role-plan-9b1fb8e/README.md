## What is and is not evidence

Repository measurements are recorded results at their own scope. Source findings
are from the pinned excerpts listed in [SOURCES.md](SOURCES.md). New formulas and
examples are conditional mathematics. [checks/results.json](checks/results.json)
contains abstract exact-rational tests, not native probability validation or
performance measurements. No native build, solve, WASM, simulator or repository
edit was performed while preparing this packet.

The scripts and evidence are small on purpose. There is no copied repository,
new supervisor, universal graph-isomorphism engine, giant symbolic solver or
approved library/ABI change in this package. Current source, runtime and CI must
be rechecked at implementation start; [evidence/baseline.json](evidence/baseline.json)
records the last observed status rather than guessing eventual results.

Run examples from this directory with:

```text
python checks/check_contracts.py --output checks/results.json
```

The manifest binds all payload bytes except itself. A passing packet check is not
solver qualification. No push or automatic successor is authorized by the prompt.
