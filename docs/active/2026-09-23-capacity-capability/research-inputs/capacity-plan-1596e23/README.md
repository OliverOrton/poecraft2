## Decision

The ordinary Calculator's C4 recovery is complete on the recorded controls. Do not repeat fixed-eight, JSON-transport, captured-row seed, or earlier proof-handoff experiments. Keep compact stepping and the accepted C4 latency trade-off.

The next primary question is **how to continue producing useful complete controllers when a single construction/retention/checking boundary exhausts the ordinary memory allowance**. The exposed case is CB06 Ring-two: the current compact worker still stops at the 1-GiB memory limit after 58 expanded states and roughly 12.36 seconds to delivery. Expanded states are not the entire retained state/support population. The first refusing owner is not identified by the checked-in compact receipt.

An older, wider-profile Ring-two run returned C1620.317 rather than C149977.251, with measured peak selected ownership about 1.62 GiB. Its time, logical-work and evaluator limits also differ. This demonstrates a valuable controller existed in broader search; it does not establish that reducing memory alone recovers it within the current product profile.

**Select P0–P4 in [CODEX_PROMPT.md](CODEX_PROMPT.md).** P0 first projects saved local evidence, adding one bounded first-refusal witness only if necessary. P1 selects exactly one supported implementation branch. A C5 unattended run is a bounded companion question, not another automatically selected implementation programme.

## What success means

A cheaper, completely checked original-root controller under unchanged product limits—not merely additional states, a smaller allocation estimate or a higher local lower. The first material target is at least 25% below both the compatible current Ring-two baseline and C149977.25092497544. Historical C1620.317 is an aspirational reference, not a promised result or optimum.

A verified memory/lifecycle repair without economic improvement can be retained with its narrower description. If no safe useful implementation is supported, return the exact unresolved witness and stop rather than widen capacities or manufacture a new candidate architecture.
