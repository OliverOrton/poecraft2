## C. Economic acceptance

Under the frozen same prices/data, W1 should return a checked policy no more expensive than the re-evaluated 424.3741 oracle when the native context still matches; W4 should similarly recover its 0.3741 oracle or something cheaper. These are feasible upper targets, not claims of optimality. Failures are investigated at their first lost stage rather than fixed by raising a cap.

For the dirty Bow, compare the same advanced root and target. Use the current independently checked clean-tail composition only as a labelled feasibility reference. Automatic success requires the solver to construct its own root policy without loading the authored answer. A from-scratch result is a different case and not an interchangeable substitute.

Finder must first demonstrate the positive executed metamod and full-root semantics; economic competitiveness is measured separately against its same-grammar baseline and Current where truly comparable. It may legitimately find a non-metamod policy cheaper. Positive usage alone is neither a better strategy nor exact closure.

Report lower provenance, result reliability/termination, candidate checks and grammar identity beside policy cost. Do not label easier coverage results clean improvements. Timing benefits require suitable matched confirmation; the initial single pairs establish case outcomes, not robust universal runtime gains.
