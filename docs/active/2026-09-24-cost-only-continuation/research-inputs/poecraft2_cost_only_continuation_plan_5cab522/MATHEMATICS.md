# From role-relative proposals to checked policy improvement

These are finite-model derivations and counterexamples, not native mechanics,
new numerical acceptance rules, or an exhaustive novelty claim. The project
already documents the main first-exit and graph-local authority arguments.
Integrate only the additional service/selection clarification once.
See [R13](SOURCES.md#r13) and [DOCS_AND_RESEARCH.md](DOCS_AND_RESEARCH.md).

## 1. The objective is an owned feasible witness

Fix an original request theta, including its physical root, goal, permitted
operations/programs, observations, native laws and prices. Let E_t contain the
compatible completely verified, actually retained proper controllers at a finite
computation boundary t. In the exact mathematical model,

    V_theta*(root) <= U_t = min_{pi in E_t} J_theta,pi(root).

An exploratory local computation does not enter E_t. If it fails, runs out of
budget or is cancelled, the retained witness remains available. The graph,
certificate, entry/context and evaluated value must stay paired. The inequality
is selection from feasible policies; it needs no statement that search has found
all improving policies or converged.

The engine's finite floating-point result still has its existing reconciliation
meaning. This derivation does not make a displayed decimal a newly certified
outward-rounded native endpoint. A proper fixed policy's value is also not a
lower bound on the optimum over all allowed policies.

## 2. An actual entry is not a free new root

Let s be a legitimate physical item/control entry reached by a complete base
controller pi. A candidate local program o has a stopping time tau and law over
native goal absorption and real boundary contexts. Define its expected cumulative
cost g_o and boundary probability row H_o. If the program exits almost surely
with finite expected cost and every boundary continuation is compatible, its
one-use-then-base value is

    Q_pi(s,o) = g_o + H_o V_pi.

Each resource can be a separate reward. All failure and cleanup outcomes are
included. This is a first-exit equation, not a success-only hit-rate heuristic.

The whole-root value also includes acquisition of s and every subsequent return.
A diagnostic local cost of two after a cost-100 prefix means a root cost of 102
in a one-pass example, not two. Saved or hand-built partial items do not authorize
free initial progress in the original request.

For the selected pilot, full recurring-controller evaluation is authoritative.
The local equation is a useful diagnostic only when g_o and H_o describe the
actual emitted physical program. A normalized repeat kernel or stripped compiler
annotation may describe a different intermediate object.

## 3. One use and repeated replacement are different

Base: cost one per attempt, self-return probability 0.9, success probability 0.1.
Its value is ten. A new attempt costs two, returns with probability 0.5, and
succeeds otherwise.

    one new attempt, then old policy: 2 + 0.5*10 = 7;
    new attempt on every return:      2/(1-0.5) = 4.

Neither equals an uncorrected “old visits times local advantage” saving. With
old expected visits ten, local advantage -3 would falsely suggest a saving of
30; the new controller's expected visits are two, giving the correct -6.

More generally, for complete proper old and new controllers on a common semantic
finite domain,

    V_pi = c_pi + Q_pi V_pi,
    V_mu - V_pi
      = (I-Q_mu)^(-1) [c_mu + Q_mu V_pi - V_pi].

Proof: rearrange the new Bellman equation after subtracting V_pi and multiply by
the transient inverse. Its nonnegative entries give the ordinary improvement
consequence when the full bracket is componentwise nonpositive. The native pilot
must not apply this test to unknown old tails or a nonuniform coarse class.

The literature connects rollout to a policy-improvement step from a base policy;
this programme uses that connection only as motivation. It does not import the
approximate aggregation architecture of [P1](SOURCES.md#p1).

## 4. Local termination is not global properness

Two locally terminating fragments can deterministically hand control to one
another forever. A complete positive exit probability from each fragment does
not prove global goal reachability. Mandatory interior state, zero-cost routers,
checkpoint/offer state, paid recovery and renewed entry interception all matter.

The existing full original-root checker remains decisive. It must reject
improper cycles, missing edges, unsupported operations, unpriced rewards and
unresolved positive mass. Do not deduce properness from finite local numbers or
merely from the base policy having been proper.

## 5. Role-relative construction need not assume symmetric values

A role-relative family can bind native parameters separately:

    template + binding b -> complete candidate pi_b -> native J_b.

For a cost-one retry versus a guaranteed cost-20 finish, p=1/5 prefers retry at
cost five, while p=1/100 prefers the guaranteed method. Ragged tier vectors and
background competitors stay in the actual native law. The same code may produce
different actions and costs; it may also correctly produce the same action when
the relative economics still favor it.

This is proposal-level generality. It is not state aggregation, transition
reuse, value transfer, a shared symbolic factorization or an all-action quotient.
Existing deictic/relative option research studies representations of this sort;
it does not discharge our specific native legality and probability obligations.
[P2](SOURCES.md#p2)

In the pilot, the relevant role is the actual missing requested family at a clean
native entry. The rest of the item, suffixes, fractures, resource keys and control
context remain part of the binding. A raw goal count cannot substitute for them.

## 6. Candidate admission is separate from proof rejection

A candidate omitted for budget or heuristic reasons has not been proved unable
to improve. Conversely, a completed more-expensive candidate is valid evidence
for retaining the old winner, but says nothing about candidates never built.

An upper estimate does not safely eliminate a candidate: incumbent10, true new
cost6, candidate upper20 is a counterexample. This is not a reason to check every
proposal. It is a reason to label unselected/screened, incomplete, independently
checked, non-improving and retained outcomes separately.

Likewise, visits times remaining cost is exposure, not disjoint spend: a four-step
cost-one chain costs four but has exposure4+3+2+1=10. The pilot preserves the old
ranking as a heuristic so activation and ranking are not confounded treatments.
Only independently evaluated full-root original cost selects the winner.

## 7. Why the service change preserves authority

At the new safe-point slot, begin from committed evidence K and private task S.
Each cooperative step either changes S alone or commits a fully checked candidate
through the original portfolio. A source-matched old controller remains owned
while construction and checking proceed. Induction then preserves the feasible-
witness invariant at every visible prefix.

This does not prove equal search trajectories, earlier verification or useful
final quality: the extra wave consumes resources and changes computation order.
Those are empirical acceptance questions. One-wave/finite-candidate limits avoid
an unbounded retry loop but are not a general fairness or eventual-exactness proof.

The new slot replaces an incidental historical prerequisite (mode plus prior
proposal sequence) with explicit artifact/entry/resource readiness. It cannot
replace any actual mechanical or certificate prerequisite. Native fixtures must
establish that correspondence. No dormant “ready” candidate is an executable tail.

## 8. Numerical and resource boundaries

All simultaneous storage counts: parent, frozen base, private rows, intermediate
and composed graphs, declarations, evaluator and frames. A 100-byte parent plus
60-byte child plus80-byte checker needs240 bytes even if each component fits a
200-byte limit by itself. Sequential peaks are not automatically simultaneous;
measure the actual ownership overlap rather than sum unrelated report peaks.

Growth refusal/cancellation releases scratch but leaves cumulative work consumed.
A saturated memory estimate cannot be reduced by arbitrary subtraction. Existing
complete audits and actual owner counters remain the authority; there is no new
memory-accounting optimization in this programme.

## 9. Research contribution and limits

The useful engineering/research target is an affordable, independently checked
post-incumbent service for native completion proposals under the original product
budget. The role abstraction supplies a reusable construction intention while
actual laws and values remain separate.

Classical rollout, first-exit equations and policy improvement are not novel here.
The cited certificate research supports separating proposal production from
acceptance, but does not supply this implicit native-model bridge. [P3](SOURCES.md#p3)
No broad novelty, exact-closure, native coefficient-enclosure or probability-
preserving state-symmetry claim follows from a successful local application.
