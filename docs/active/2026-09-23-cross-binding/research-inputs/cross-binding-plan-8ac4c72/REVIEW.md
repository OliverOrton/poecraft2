Whether doing that saves material work in this engine is still unknown.

## 3. Why the stop-set trial could collapse

The native normalization code does not blindly retry every result missing the named target. It retries only when the result both misses that stop predicate and is certified attempt-equivalent. A non-equivalent result already exits to the outer policy. [R6]

For a fixed attempt and retry-equivalence set R, changing stopping set T1 to T2 cannot change the normalized outcome mapping when R intersect T1 equals R intersect T2 and the other admission/terminal conditions stay the same. The proof is in MATHEMATICS.md. Thus adding named stopping outcomes that were already outer exits can add descriptions without adding decisions.

This is a sufficient explanatory mechanism supported by source, not a per-candidate diagnosis of all 828 additional collapses. The aggregate receipt alone does not identify each collapsed candidate's canonical representative. If useful, inspect one saved mapping or one small native example; do not repeat the full pair-stop solve merely to narrate the negative.

## 5. Selected hypothesis

There is a native family of finite computations in which roles, exclusion relationships, observation/control flow and output structure can be represented once, while actual native weights, family members, resource prices and physical successor maps vary by binding. A bounded request-local template can specialize those computations at lower total cost than rebuilding the structure independently.

The direct test must show one shared structure being used for at least two genuinely distinct heterogeneous native bindings with unequal numeric output. The later caller must not reconstruct the entire concrete graph merely to discover that it matches the first one. The contract and matching cost count toward the result.

The strongest implementation candidate is a role-parameterized transition/continuation computation already owned by the native engine: its structural recursion or equation sparsity is reusable; its coefficient vectors, routing and value results are not automatically reusable. Prefer the first existing expensive repeated operation exposed by the user-relevant entries. A whole-solver symbolic MDP, a new CAS or a general recipe library is not selected.

## 6. Why the hypothesis is plausible, and why its payoff is uncertain

Parametric Markov models separate symbolic structure from numerical instantiation; relativized options separate a relative control representation from its concrete action mapping. Arithmetic circuits provide precedent for compiling inference structure once and reevaluating parameters. These supply useful concepts, not a native mechanics proof or performance forecast. [P1–P4]

The hard limits remain: genuine suffix/control distinctions can break the common shape; new weights can change supports and properness; exact output materialization can dominate; preserved native information must not disappear into an average; the existing caches may already eliminate most repeated work. Three-label exact symmetry has orbits of size at most six. More general parametric sharing is not subject to that same small family-of-labels interpretation, but does not magically remove all numerical bindings or physical outputs.

A meaningful negative result here would identify the actual failed premise: no common native shape, no repeated expensive misses, expensive matching, dominated output/checking, or no all-in saving. It would still not imply that heterogeneous states can be merged into one cost, nor establish all role abstraction is ineffective.
