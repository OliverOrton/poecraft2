# Cross-binding weighted solver structures

**Research/review baseline:** OliverOrton/poecraft2 `8ac4c72de5b35a4d7080ebbdd8b69983af7e6772`.
**Selection:** G0–G4 in [the milestones](MILESTONES.md). Start implementation with [CODEX_PROMPT.md](CODEX_PROMPT.md).

The previous role-parametric programme tested multi-target protected-repeat stops and memoization of an identical physical attempt inside one carrier. Neither met its gate; both were removed. Those negative results must stand. They do not constitute a test of compiling one weighted structural computation and using it for several different native family bindings.

This packet selects that missing experiment. Its primary subject is unequal families, not approximate merging or a perfectly symmetric toy. Build or discover structure once where a native contract permits it, specialize actual coefficients and outputs per binding, and let policy decisions differ. Do not replace the experiment with another exit-set expansion or same-entry memo.

The first deliverable is a real native cross-binding consumer, not a descriptor library. A useful performance result additionally needs measured saved construction/evaluation work on naturally occurring distinct bindings after existing caches, including matching and output costs. A new full-root strategy-quality result is a separate stronger outcome. Neither is predicted.
