5. Missing/ambiguous upgrade mapping or any conflicting pair refuses the whole
   row/evaluation. Do not publish a partial distribution.
6. Continue existing exact graph evaluation from every positive-mass successor,
   preserving action cost, failure, stop, nonapplication, unmatched-edge and
