## Objective

Derive a typed, independently validated statewise executable-continuation
upper certificate from the already compiled and exact-evaluated closed-domain
PDR strategy. Feed it first to a zero-authority audit over existing operator
and strict-obligation lowers. Promote only a narrow handoff when the existing
lower is measurably useful; build one proof-only RC refinement only if the
statewise 3,758-Chaos comparison proves that an existing lower remains too
weak.

The required order is:

```text
exact-evaluated root strategy
  -> independently valid statewise continuation uppers
  -> existing-lower shadow audit
  -> narrow existing-consumer handoff, or one evidence-selected RC shadow
```

## Authority Distinction

Keep separate: public root executable upper, coarse solver estimate, fixed-
strategy statewise continuation upper, admissible proof lower, and optimal or
current-greedy value. A statewise certificate proves only
`V*(state) <= J_policy(state)` for its fully bound entry/domain. It has no
conversion to a lower, exact closure, state equivalence, transition
probability, terminal truth, or incumbent publication.

For a behavioral representative with several exact physical members, expose
an upper only after complete member coverage, route coverage, arbitrary-entry
properness, finite exact fixed-policy cost, and identity equality are proved
for every member. Publish the maximum member cost; refuse incomplete classes.

  evaluation as statewise pruning authority.

  scheduler, resumable ownership, fragments, planner, MCP/GUI, caps, or strict
  final exactness.

  incomplete-member evaluation exposes no positive statewise certificate.
- Do not presuppose Harvest or build an RC portfolio before the new shadow

## Decision And Outcome

**Combined Outcome C/D; diagnosis-only.** The evaluator now owns a sound,
amortized arbitrary-entry certificate primitive, but the current production
adapter can safely bind only the exact requested root. The smallest missing
authority contract for other solver states is a complete collision-safe map
from each coarse/behavioral representative to every exact physical member and
its compiled route. Coarse values cannot fill that gap.

For the one entry that is certified, the correct upper arrives after the
coarse action ledger is fully materialized and no existing operator lower is
within `2,965` Chaos of retirement. Strict alternatives are already absent.
There is therefore no real remaining lower-bound consumer, no evidence-selected
RC action/state shape, and no lawful production retirement handoff. Outcome A
usefulness gates and Outcome B selection gates both fail. No RCASSP, pruning,
scheduling, publication, lower, upper, incumbent-selection, or lifecycle
authority was added.

The retained result is the typed evaluator certificate and bounded
observational audit, which replace the former unsound copied-incumbent-value
shadow with explicit refusal and exact identity/member evidence. Strict final
exactness remains mandatory; the early direct candidate remains only a verified
bounded executable upper while the coarse/exact delta remains. The next solver
boundary is unselected and must not be inferred from this diagnosis.
