## Uniform contract and its limitation

For a native item `s`, let `G(s)` be its exact satisfying goal-slot mask. The
native support helper supplies `R(a)`, a superset of every goal slot a primitive
can introduce, for **all** native members and item tag signatures in the fixed
session. Thus each applied primitive has:

```text
G(s') subset G(s) union R(a)
c_lower(a) <= actual paid primitive cost
```

The opt-in mode deliberately omits fresh-base weight positivity: influence tags
can activate other modifiers. It retains native natural, targeted, guaranteed,
fossil, bench, influence and unveiled support ownership. Exclusion groups,
protection, fracture, offers, roll values and correlated draws can remove
possibilities but cannot escape this complete support union. Unknown primitive
or companion-state semantics refuse certification.

The frozen finite table is checked for nonnegativity, zero at every relaxed
goal mask, monotonicity under adding goals, and every inequality:

```text
h(M) <= c_lower(a) + h(M union R(a))
       <= actual_cost(a) + h(G(s'))
```

This pointwise relation implies the expected-potential relation for every
normalized native outcome law and every observed choice. It does not assert
identical kernels or turn an optimistic deterministic row into a native exact
kernel. Goals may receive zero before exact rarity/junk-free terminal conditions
hold; that only weakens a lower bound. Failed no-op applications satisfy the
identity inequality at zero cost.

Every priced registry primitive is covered, including constituents beyond the
current selectable catalogue. All nine current runtime program productions and
ten generated families are covered by composition: a virtual union of goals ever
acquired permits free preservation through conditional paths, observed choices,
cleanup, retry and Imprint's internal return-to-entry. Extra nonnegative setup
costs may be dropped for this donor proof. Runtime dependencies remain registry
indices; native automatic admission checks every constituent's prices. Priced
static programs with an unpriced dependency refuse. Unknown family/production
vocabulary refuses. No materialized catalogue is promoted to a family census.

The underlying finite potential is global within this fixed session/action
universe, so it also supplies an independently valid escape outside a published
phase view. A view nevertheless binds both Eldritch tiers exactly. Its domain
allows all native-valid rarity, occupancy, protection, fracture and influence
coordinates; this particular repaired function ignores those coordinates.
It does not change the global state representation or the old anchored guard.
Reuse requires the same immutable session and full goal, registry parameters,
static caller scope, family vocabulary, prices, phase, numeric schema and frozen
values. The incumbent is absent. There is no cross-run deserialization path.
The finite bounded potential uses the existing proper-policy objective with
non-success valued at infinity; no infinity certificate or new zero-loop
semantics is claimed.

The existing **universal goal-cover** table is a proposal to this checker, not
native authority. It fails this stronger, deliberately coarse pointwise cover;
the existing quotient repairs it. The medium repair assigns Transmute's price
0.01165 to all 31 non-full masks and zero to mask 31. Granting every missing goal
for one Transmute, without rarity/capacity/probability distinctions, is the exact
limiting relaxation. This is **not a native counterexample to the old 36.43
anchored donor**. The stronger old probabilistic rules still lack the consumed
uniform expectation witnesses needed to preserve that value.
