# Solver Development Checkpoint/Replay

**Status: completed 2026-08-27.**

Parent: [Documentation archive](../README.md)

- [Plan](plan.md)
- [Result](result.md)

This milestone implements honest native cross-process reuse of a completed
coarse solver graph. The checkpoint includes the calculator's ordered states,
dynamic operators, state-local automatic admission authority, action-envelope
evidence, and all behavior-bearing sparse graph arenas. Replay reruns Bellman,
strict refinement, compilation, and exact evaluation normally.

The format is an iteration aid, not product state or proof authority. Release
WASM has no checkpoint export. A strict-partition checkpoint remains a
separate possible extension because it would need the persistent proof store,
partition generations, obligations, kernels, cursors, and incumbent.
