## Objective

Turn a normally generated, independently evaluated clean-five executable
strategy into an isolated exact-policy-entry and complete-alternative proof
census. Attach its statewise executable continuation uppers to the existing
proof-carrying quotient identities, compare them with existing admissible
lowers in a zero-authority shadow, and select one RC refinement only if the
measured closest competitive population requires it.

The required order is:

```text
verified current-run strategy
  -> exact reachable strategy decision entries
  -> existing strict exact-state/action identities
  -> complete caller-authorized alternative obligations
  -> statewise-upper / existing-lower shadow
  -> narrow existing consumer, or one measured RC shadow
```

## Source Audit Decision

1. The exact evaluator owns collision-safe pairs `(compiled node, exact
   evaluator state, checkpoint state, observed offer)`. It discovers the
   positive-probability closure from the requested root, proves fixed-policy
   SCC properness, solves one continuation Bellman system, and can materialize
   exact items. The raw pair key already includes authored node identity,
   exact item semantics, checkpoint semantics, and fixed observed-choice
   memory.
2. `StrategyEvalResult` currently retains positive-occupancy operation rows,
   but it does not retain a typed census of genuine compiler policy-decision
   entries or their selected planner-operation identities. Operation rows
   alone are insufficient: fixed programs contain downstream operations,
   observed choices contain routers, and checkpoint/route nodes are not new
   action decisions.
3. The compiler is the smallest safe owner of decision-entry provenance. It
   knows the exact emitted entry node, source policy state, selected
   `PlannerOperator`, and canonical semantic program identity. Parser-local
   indexes and display labels are not reusable authority.
4. The proof-carrying quotient already builds a semantic strict child,
   imports the complete caller-filtered planner vocabulary, enumerates exact
   per-carrier applicability, preserves fixed-option/choice programs, creates
   separate selected and alternative obligations, accounts proof memory, and
   supports conditional noncompetitive retirement.
5. A bounded coarse solve is not itself a blocker. The existing quotient
   deliberately creates alternative obligations unless the coarse result is
   already exact. Its blocker is selection ownership: `ProductionPolicyOracle`
   installs `SolveResult.policy[coarse_state]` as the selected action and has
   no input contract for a verified compiled strategy entry.
6. The verified strategy can therefore seed the existing strict machinery
   only after a collision-checked bridge proves: exact item projection,
   behavioral representative membership, compiled decision-node identity,
   selected planner semantic identity, checkpoint/offer compatibility, and
   full request/strategy/caller identity. Unsupported entries must be refused.
7. The bridge can remain shadow-only: capture and comparison occur after
   independent evaluation and are not read by ordinary search, scheduling,
   action-envelope lifecycle, proof lifecycle, incumbent choice, public
   bounds, or publication.
8. The statewise upper is available on the evaluator pair before strict
   alternative rows are materialized. The bridge should attach it while the
   exact strict source state and complete admitted alternative vocabulary are
   being created, not after reconstructing a whole exact graph.
