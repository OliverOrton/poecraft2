archive's `reference.json`, `ordinary-{cold,warm}.json`, `development-{cold,warm}.json`
and `provenance.json` there (name the latter `probe-provenance.json`). Then:

```text
py -3 engine/benchmarks/verify_quotient_lower_probe.py proposal-warm.json reference.json
py -3 engine/benchmarks/verify_quotient_lower_probe.py --numerical-reuse EVIDENCE_DIR comparison.json
```

The first command reads the compact native file; give its actual path when outside
the evidence directory. The second checks matched identities and reports gains;
it does not issue native authority itself. Canonical reporting commands remain in
[benchmarking](../../solver/benchmarking.md#research-series).
