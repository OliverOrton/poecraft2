# Bounded Executable-Upper Completion And Imprint Applicability

**Status: complete and accepted.** See [result](result.md). Oliver selected
this chunk on 2026-08-22. It owns the
incremental executable-upper stall exposed by the checked Imprint-disabled
four-T1 run, honest native publication before an external watchdog, and only
proved carrier-local Imprint applicability. It does not change crafting
mechanics, silently remove Imprint from the default action scope, or begin a
new exact Imprint kernel architecture.

## Evidence entering the milestone

- The default-on four-T1 control stops at `max_imprint_program_work` in
  44.823 seconds and publishes an independently evaluated 3,759.976312-Chaos
  bounded policy.
- With only automatic Imprint programs disabled, the same solve reaches the
  same certified lower and a provisional 22,103.310237 upper, then the
  external five-minute watchdog abandons it without a result.
- The disabled trace starts only five more incremental upper-policy passes,
  but grows from 1,591 to 233,867 fixed-policy evaluations, from 9,333 to
  2,564,397 sparse iterations, and spends 284.232 seconds in optimization.
- Source inspection shows that an incremental executable-upper pass continues
  into Howard improvement whenever the inherited Bellman residual exceeds the
  normal convergence tolerance. A completed exact proper fixed-policy
  evaluation already proves a feasible upper; Bellman optimality on the
  partial graph is not required to publish it.
- Automatic Imprint discovery already checks checkpoint legality at the exact
  carrier and returns for ineligible states. The remaining expensive programs
  occur on genuinely legal reachable Magic carriers, so another rarity-only or
  base-wide filter would be cosmetic rather than a solution.

## Gates

1. **Executable witness, not partial-graph optimum.** Make an incremental
   upper-policy pass stop after its first completed exact proper fixed-policy
   evaluation. Preserve the incumbent comparison, selected temporary-row
   promotion, independent final certification, lower-bound authority, and all
   exact-closure obligations. Add a focused native regression whose inherited
   residual is deliberately large and prove the pass performs one evaluation,
   publishes only a proper feasible upper, and does not claim exact closure.

2. **Measure the repaired disabled witness.** Re-run the canonical four-T1
   case with only `consider_imprint_programs: false`. Compare fixed-policy
   evaluations, sparse iterations, pass count, optimization wall, bound
   trajectory, remaining envelope work, and publication. This measurement
   decides whether another batching layer is justified; do not add an
   arbitrary pass-count threshold.

3. **Natural batching only if it still owns material wall.** If repaired
   one-proof passes remain material, batch competitive rows at a stable
   scheduler boundary: all alternatives evaluated against one unchanged
   incumbent/frontier epoch enter one policy proof. Do not use elapsed time,
   a magic action count, or suppress a previously published incumbent. Prove
   that batching changes scheduling only, not row legality, Q authority, or
   the final result on a closed focused fixture.

4. **Native bounded publication if the envelope can still outrun product
   ownership.** If the repaired canonical run still reaches the external
   watchdog, add a deterministic cumulative work budget at the actual costly
   unit. On exhaustion, roll back temporary admissions, retain the last
   independently evaluated incumbent, leave every unfinished alternative
   disclosed, and finalize as bounded rather than exact. Thread any new public
   option append-only through C ABI, WASM, Calculator defaults, cache identity,
   telemetry, progress, and documentation. Do not substitute wall-clock
   authority for deterministic solver work.

5. **Imprint applicability and recovery dominance.** Retain the existing
   state-local Magic checkpoint legality test. Audit for a stronger cheap
   applicability predicate, but implement it only when the solver proves that
   no admitted continuation can use the checkpoint or that a proper
   non-Imprint recovery policy returns every relevant failure class to the
   same observable Magic carrier equivalence class at no greater expected
   cost. Goal count, primitive price, rarity alone, or recovery to an
   arbitrary Magic item are not sufficient proofs. If no cheap proof covers
   the expensive carrier, record that exact boundary rather than adding a
   heuristic exclusion.

6. **Focused acceptance and release parity.** Build native, run the focused
   solver/API/compiler checks affected by the change, run the canonical
   enabled and disabled four-T1 controls plus the existing Imprint retry and
   Warlord controls, rebuild release WASM for any native behavior/ABI change,
   and run TypeScript plus complete automated web tests. Run 10,000 simulator
   trials only when a newly compiled strategy requires verification. Do not
   run the full repository pipeline unless a cross-layer result cannot be
   qualified proportionally.

## Acceptance

- No upper pass repeats Howard improvement merely to optimize a feasible
  witness on an open partial graph.
- A completed fixed-policy proof remains proper, executable, and independently
  certifiable; it never raises the lower bound or closes the open action
  envelope.
- The canonical disabled witness either completes within five minutes or stops
  natively with a bounded strategy and precise unfinished-work telemetry.
- Default-on Imprint behavior changes only under a documented proof. Imprint
  remains available on every mechanically legal carrier not proved irrelevant
  or dominated.
- The result names whether the measured owner was repeated policy improvement,
  scheduling frequency, remaining envelope materialization, or Imprint kernel
  work; it does not infer one from wall time alone.
