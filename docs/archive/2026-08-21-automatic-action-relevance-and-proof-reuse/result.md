## Retained Work

- Parent-context Eldritch fixed programs now use their complete priced
  resource vector before kernel construction. A certified carrier upper below
  that exact nonnegative immediate cost rejects the option without building
  its reforge kernel.
- Parent-context Eldritch programs with the same complete exact kernel keep
  deterministic first authority. When only their resource vector differs and
  prices are concrete, the cheaper exact-transition representative wins.
- The existing state-incumbent heuristic now prices the complete expected
  resource vector of a state-local automatic option. Authored conditional
  fixed programs retain the conservative guaranteed-first-primitive rule.
- An Imprint work-cap stop now records the mechanically open frontier program
  that had not yet been evaluated. This is diagnostic evidence only and does
  not change admission.

The Eldritch rejection is sound because the fixed program pays the retained
resource vector before any nonnegative continuation. The automatic-option
heuristic is sound because state-local publication replaces construction
quantities with the exact carrier-local `OptionKernel` expected resources.
Neither rule treats a non-goal affix as irrelevant; occupancy and blocking
effects remain in the complete kernel.

## Audit Corrections

The proposed Imprint rewrite was based on a stale diagnosis. Current discovery
already canonicalizes exact support kernels, eliminates exact root cycles,
keeps collision-checked Pareto representatives, applies componentwise
primitive-count dominance valid under every economy, and uses positive-price
producer bounds. The state-928 carrier still stops at 256 evaluated programs,
but it now names the next unevaluated frontier:

`annul > augment > fossil:...BleedPoison+...Defences+...Enchant+...Lightning`

with reason `work_cap_before_evaluation`. Its measured boundary remains 61
frontier entries, depth 3, 182,778 action-state evaluations, and 2,570,418
merged outcomes. Raising the cap and previously rejected scalar price ordering
experiments were not repeated.

Strict proof also already owns more reuse than the plan assumed. Each
alternative obligation covers every exact carrier in one quotient cell;
certified row identities, payload interning, coverage, price identity, and
generation checks are collision-safe. Sharing a verdict across different
cells would still be unsound when their successor continuation projections
differ.

One stronger carrier-wide lower trial threaded the coarse solver's admissible
goal-cover bound into strict obligations. It produced the same 11,384 coarse
rows, 29,135 transitions, 17,584 open actions, and repeated strict-pass shape,
then expired at 300.12 seconds. That plumbing was removed rather than retained
without measured value.
