Existing `solve()` computes the one-step lower then requires entries to belong to the certified terminal attractor (`:823-827`), so it is the wrong entry point for optimizing off-incumbent lower cells.

## Concrete correctness guard found during audit

The generic envelope row helper is not safe to copy as the universal observed-choice proof kernel without a fix or a refusal guard. It minimizes finite nonself successors and only uses `group.has_self` when no finite nonself successor exists (`solver_solve_envelope_proof.cpp:79-96`). But sparse rows store self separately: `solver_sparse_policy.cpp:122-143` turns an owner successor into `has_self=true` and excludes it from `choice_successors`; the broad construction does the same at `solver_solve_expand.cpp:2687-2698`.

Adversarial synthetic row: immediate cost 1; probability 1/2 terminal; probability 1/2 observed offer `{self,t}`; boundary value at t is 100. The existing envelope formula returns 51. Repeatedly choosing self yields cost 2, so 51 is not an admissible lower. This establishes a source/representation counterexample, not that a current native clean-five row actually has this shape. The retained shared sparse helper already solves the correct row-local equation `x=constant+p_self*x+sum g*min(x,alternate_g)` (`solver_sparse_policy.cpp:226-290`) and is the arithmetic reuse donor. Keep this as a necessary adversarial fixture before authority promotion.

Similarly, `validate_proof_pattern_subsolution_fixture` in `solver_proof_pattern_manager.hpp` checks only supplied rows, probability at most one, finite nonnegative values, goal zero, and approximate inequalities. It is a fixture helper, not an action-coverage or numeric-error certificate.

## Original Markov state versus compiled provenance

`AbstractState` (`solver_model.hpp:1278-1317`) includes goal/member identity, exact crafted/fractured bits, blocking groups, occupancy, rarity, influence, Veiled side, Eldritch dominance, flags, fractured metamods, junk classes, and retry-basin marker. Concrete item facts required by mechanic applicability, transitions or terminal recognition belong in the original model or its proved sufficient projection. Base/session/data/goal/caller scope belong to authority identity even when constant per solve.

The retry-basin field is especially subtle: it is a virtual Bellman action restriction, not a physical item fact (`:1306-1309`). Removing it while keeping restricted caller semantics changes legal actions. Imprint checkpoint state and an observed offer/program phase are original decision-process memory **when the enabled action/program semantics depend on them**. They cannot be discarded merely because a particular compiled strategy represented them as controller nodes.

Compiled graph node, decision-entry identity, parser-local node index, representative coarse routing class, selected-policy provenance, strategy SHA, and exact evaluator `(node,item)` pairing belong to controller/executable evidence. Lower variables at physical decision boundaries need not be keyed by this controller provenance. However converting a mandatory option into primitive states requires explicit phase/checkpoint/observation memory to preserve the actual decision timing. This is not permission to grant free interruption or free setup.

Canonical PlannerOperator semantics deliberately exclude presentation fields and local numeric handles while including companion action IDs, ordered program dependencies, setup/followup/cleanup, automatic kind, side/goal and resource quantities (`solver_model.hpp:815-895`). Use these canonical sets and collision-checked keys, not counts/dense IDs.

## Small changed invariant and recommended next boundary

Old lower-domain admission is entangled either with a selected compiled policy entry/kernel (fixed-J shadow), coarse admitted search graph, or a preselected clean finite projection. Proposed smallest invariant change:

> A persistent lower cell may exist solely because its canonical original decision-state and caller scope are known. It requires no incumbent entry or selected executable continuation. Every legal action/choice is covered exactly once by an exact/proved optimistic constraint or a canonical open-family placeholder; all outgoing outside mass carries an independently admissible identity-bound boundary lower. Free values become authority only after complete scope and conservative simultaneous inequality validation.

Initial implementation boundary should adapt existing sparse/proof storage to one small lower-only model, keeping fixed-J as an opportunistic comparator. Introduce set-level coverage and correct shared choice arithmetic before authority. Add neither a production LP dependency nor broad exact-domain expansion. Choose a minimum-owning cheap placeholder first and measure a single retention/capacity/program refinement that attacks its precise favorable assumption. Use current native micro/medium artifacts and second source shape to distinguish useful reuse from exact expansion repeated under another name. If projected exact row work dominates, stop at a measured projected-expectation contract instead of scheduler changes.

The strongest objection is that current scalar/free-preservation placeholders may pin all useful values near existing floors, while tightening them requires the same large physical branch work that previously failed. Existing sources establish sound places to integrate and some prior retention success, but do not establish clean-five practicality. ## Monotonicity and infeasible-lift caveat

An independently admissible base vector need not satisfy every Bellman inequality. For deterministic zero-cost s->t followed by cost-10 t->goal, b(s)=10,b(t)=0 is admissible but b(s)>0+b(t). More strongly, a relaxed finite model can have an independently valid exact-state lower above its own optimum when some cheap placeholder grants extra power. Therefore one cannot impose all prior independently admissible values as lower bounds on LP variables and assume feasibility, or assume raising domain size automatically yields a monotone model optimum. A newly explicit row may initially be weaker than the scalar action lower it replaces because c+E[b] can be below an independently admissible scalar lower on the real Q.

Prove extension using a Bellman-consistent feasible lower seed, a dominating refinement relation for the exact/projection/placeholder models, and compatible identity/boundary updates. Otherwise each validated model lower remains independently admissible, and reporting max(previous certified lower,new certified lower) preserves root monotonicity **externally** without claiming the maximum vector is feasible for that finite model. Candidate repair from J must allow decreases. If existing lower constraints make the relaxed LP infeasible, diagnose incompatibility of modeling/seed constraints rather than declaring the real crafting state unsolvable.
