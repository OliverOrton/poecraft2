# Native Solver Lab Case Authoring

**Status: completed and archived.** Oliver selected this boundary on
2026-08-28 after exercising Native Solver Lab v0; implementation and
acceptance completed the same day.

Parent: [Documentation archive](../README.md)

Before this boundary the Lab ran five frozen research cases but could not
create or revise local cases. This boundary adds a revision-safe authoring bridge from
the browser Calculator to the native Lab, exposes the same lifecycle through
GUI, CLI, and the closed MCP adapter, and registers the user-local MCP server
for Codex with this checkout as its explicit root.

The historical execution contract is the accompanying [plan](plan.md). The
implemented outcome and acceptance record are in [result](result.md).
