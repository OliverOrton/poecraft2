Phase P3a image-model examples for replacing the Calculator-only Goal
requirements list with the same shared item-frame UI used by Input item.

- `variant-a-literal-twin.png` - target controls sit above the shared frame and
  tier/remove controls are explicit on occupied rows.
- `variant-b-quiet-target-frame.png` - the item silhouette dominates and goal
  controls move to a compact footer.

The overall Calculator layout, native result values, one-action behavior, and
v1 goal semantics are fixed. Image text is illustrative; hierarchy and control
placement are the review target.

Generated with the built-in image tool on 2026-07-14 from the prompts in this
directory and the three recorded references. Known image-model fiction must not
enter implementation: Variant A mislabels the Input item's `S3` empty row and
shows target section counts as capacity; Variant B's Odds headline says
`At least 2 of 3` while its footer says `All 3`. Runtime labels, target counts,
and odds remain engine/model owned.
