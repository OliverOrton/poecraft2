# Product Design Archive

**Status: historical product-design evidence.** These briefs, specifications,
mockups, prompts, and reference images record the July 2026 design process;
they do not define current product behavior.

Parent: [Archive index](../README.md)

- `briefs/` contains point-in-time design briefs.
- `specs/` contains approved implementation specifications.
- `mockups/` contains review notes, prompts, and generated/reference images.
- `refs/` contains screenshots used during that work.

Current implemented product contracts live in [Product](../../product/README.md).
