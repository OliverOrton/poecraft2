# Protected-Core Compression Ceiling Census

**Status: complete.** Oliver selected this falsification-first measurement on
2026-07-27. The cleanup-specific direction was rejected at Gate 3 and all
measurement-only engine source was restored.

Parent: [Milestone archive](README.md)

## Objective

Measure whether opposite-side cleanup could possibly remove enough of the
first broad-reforge state explosion to merit a cleanup-route or dominance
implementation.

The experiment deliberately grants cleanup an impossible advantage: it groups
observed complete successors by projections that erase prefix contents,
suffix contents, or all non-goal contents without charging resources,
retaining failure exits, or proving that cleanup is legal, mandatory, or
optimal. If even that ceiling is weak, exact cleanup cannot be the next
pre-bound scaling architecture.

## Fixed interpretation

- This is an observed-prefix census. The hard solve stops while constructing
  the broad row, so the report must not call the observed stream a complete
  transition kernel or claim complete probability mass.
- Projected signatures are collision-checked measurement keys, not solver
  states, equivalence classes, option exits, conditions, or proof authority.
- The baseline solver still interns every successor in its original order.
  The census cannot change action admission, state identity, graph contents,
  work counters, bounds, policies, caps, termination, or hashes.
- No cleanup route, stochastic repair, affine alias, source-elimination
  certificate, finish contract, or upstream condition integration is
  implemented.
- No mechanic ruling is required. The census does not execute Annul, Scour,
  Harvest, Eldritch, a metamod, or any new action program.
- The four frozen hard natural-T1 cases and their production limits remain
  unchanged. No cap increase, adaptive racing, GPU work, ML, exact oracle,
  compiled-policy evaluation, or 10,000-run simulation.
- Diagnostic storage and work are reported separately and honestly. A
  diagnostic failure, timeout, or survivor is a failed measurement.
- Commits remain local-only and end with
  `Co-authored-by: Codex <codex@openai.com>`.

## Gate 0 - Contract and ownership

1. Pin source, executable, artifact, generator configuration, economy, cases,
   limits, compiler, and machine.
2. Map the final raw-successor commit point, state-cap interruption, reforge
   cache, telemetry snapshot, benchmark ingest, and evidence ownership.
3. Freeze three projections:
   - prefix core: retain prefix-side goal and junk information while erasing
     suffix-side contents;
   - suffix core: retain suffix-side goal and junk information while erasing
     prefix-side contents; and
   - goal core: retain goal progress and item-wide identity while erasing all
     non-goal affix contents.
4. Freeze report language: counts cover only unique successors successfully
   observed before the ordinary state cap interrupts the selected reforge.

## Gate 1 - Measurement-only census

1. Observe the fully constructed `AbstractState` at the existing reforge
   outcome commit point.
2. Identify the cap-causing reforge attempt without requiring a completed
   row. A normally completed smaller attempt may be discarded or retained
   only as context.
3. For unique newly interned successors in the active attempt, record:
   - full-state count;
   - terminal and goal-progress counts;
   - prefix-, suffix-, and goal-core signature counts;
   - maximum and percentile fan-in;
   - prefix/suffix occupancy distribution;
   - action/source identity, observed reforge work, wall time, and completion
     state; and
   - diagnostic bytes and collision checks.
4. Publish enough state in the cooperative incomplete snapshot for the
   benchmark harness to preserve the census after the expected state-cap
   exception.
5. Add narrow native tests for projection determinism, collision-checked
   identity, no-census behavior, incomplete-at-cap publication, and unchanged
   ordinary outcomes.

## Gate 2 - Four-case falsification

Run the frozen full/deep three- and four-target hard cases once under the
unchanged production caps.

Reject cleanup as the next pre-bound scaling direction if either protected-side
projection has observed-prefix compression below `2x` on every hard case, or
if the goal-progress population to which the motivating cleanup applies is
too small to create material state-cap headroom.

A projection above `2x` is only an invitation to a later complete-kernel and
proof-feasibility study. It does not qualify cleanup, state substitution, or a
production change.

## Gate 3 - Decision and restoration

1. Record observed counts, deterministic work, machine-bound wall time,
   incomplete-stream limitation, watchdog state, and survivors.
2. Restore diagnostic-only engine source unless the telemetry is compact,
   generally reusable, and justified independently of this rejected or
   inconclusive candidate.
3. Do not select a cleanup primitive or request mechanic rulings unless the
   ceiling is strong enough to justify a separate milestone.

## Gate 4 - Acceptance and handoff

1. Run the affected focused native calculation/solve checks and benchmark
   ingest checks once after the final retained path is known.
2. Rebuild WASM or run downstream web checks only if retained engine behavior
   reaches the browser solver path.
3. Store a versioned evidence summary with source identity and portable
   deterministic measurements.
4. Extract durable facts into the solver/evidence documentation, archive this
   plan, clear the active boundary, update `HANDOFF.md`, and create one local
   completion commit.

## Completion criteria

This milestone completes with one honest result:

- a pinned rejection of protected-core cleanup as the next pre-bound scaling
  direction; or
- an inconclusive/positive observed-prefix ceiling that names the exact
  missing complete-kernel and proof-feasibility work without implementing it.

It does not complete by labeling a projection as equivalence, extrapolating a
censored prefix to the complete kernel, inventing a cleanup certificate, or
retaining measurement code merely because it exists.
