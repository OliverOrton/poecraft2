# Selected-Closure Scaling And Exact Broad-Row Projection — Final Report

## Outcome

The exact sparse projected frontier is retained as research code but rejected
for production integration. It is semantically equivalent to the raw oracle
on the exercised scope and materially lowers the comparable work ledger, yet
does not meet the milestone's binding performance threshold.

The raw frontier remains the product default. The solver's 20M default is not
raised. Gates 6–8 were skipped by condition.

## Selected-closure cap decision

The one authorized selected-first 100M diagnostic completed 40 selected rows
and 6,903,840 transitions while reaching no partition, alternative obligation,
or executable upper. Marginal completed rows remained flat at 172,596
transitions and about 2.105M work. A 200M run was therefore forbidden and no
higher product default qualified.

## Causal attribution

The first source-authoritative broad row is the root Zeal Essence program. Its
post-forced pool contains 259 modifiers / 210,650 weight and becomes 39
physical families / 40 roll buckets. Raw construction visits 51,155 frontier
states, commits 688,739 terminal arrivals, and produces 172,596 strict
projected outcomes. Raw identity-table and identity-tree work are both zero.

Of the terminal arrivals, 516,143 are later arrivals to an already-created
projected target and carry 0.25435223351246694 probability mass. The dominant
cost is exact within-roll availability and terminal branching, not literal
junk-modifier identity.

## Projected prototype

The V2 frontier adds a collision-checked interned availability bitset to the
existing exact projected roll state. A bucket remains set only while it has
positive natural weight, open side capacity, compatible goal occupancy,
remaining multiplicity, and no generation-group conflict with a prior pick.
The same parameterized pool and absorption code covers ordinary reforges,
Essence, Harvest, and Fossil mechanics.

The raw path stays independently selectable. Work is reported in parallel:

- V1: historic state node plus every roll bucket;
- V2: sparse state node plus availability words inspected plus every eligible
  edge; and
- common raw-choice, guaranteed-scan, and identity-expansion work is charged
  to both.

`max_reforge_work` applies to the active evaluator, and every report preserves
both ledgers.

## Equivalence

Focused synthetic tests compare ordinary Chaos-like, forced Essence,
guaranteed-target Harvest, and Fossil rows with positive and zeroed weight
effects. Forward and reversed raw/projected traversals agree on total mass,
every canonical projected target, and goal/below-tier probabilities.

Real artifact checks use an empty rare and a fractured rare on Vaal Regalia,
covering Chaos, Essence, Harvest, and Fossil. Legality, canonical maps, and
goal mass agree. A real Bellman solve also agrees on evaluated value and the
selected semantic action. The focused command completes 250,713 checks with
zero failures.

## Binding performance result

The same 18M hard carrier used for Gate 3 attribution was run with only the
native diagnostic projected-frontier flag added. It is not a rerun of the
frozen/original 20M case or the selected-first 100M diagnostic.

| Metric | Raw Gate 3 | Projected Gate 5 |
| --- | ---: | ---: |
| Comparable row work | 2,097,355 | 923,141 |
| Required maximum | — | 300,000 |
| Frontier states | 51,155 | 51,155 |
| Strict transitions | 172,596 | 172,596 |
| Terminal arrivals | 688,739 | 688,739 |
| Row total wall | 0.809 s | 1.004 s |

V2 reduces work by 55.99% (2.27×), but remains 623,141 work over the gate and
3.08× its ceiling. It also increases row wall by about 24% because bitset
interning does not remove the dominant final-depth accumulation.

Gate 3's 236,980 sparse proxy counted the 185,825 positive edges that extend
the next frontier. It omitted 638,365 eligible final-depth branches that
commit directly in goal-progress-gated mode. Gate 5 counts those branches as
real work. Excluding them would silently weaken the operational cap rather
than optimize the algorithm.

The 18M diagnostic completes four selected rows and consumes the full
3,922,368 post-coarse allowance, but still reaches no partition or executable
upper.

## Timing, memory, and release scope

The projected report takes 11.717 seconds total and 5.966 seconds in solve;
its longest cooperative step is 1,042.362 ms. Native selected-owned memory is
305,299,424 bytes live and 375,485,183 bytes peak, effectively unchanged from
the raw boundary.

No policy is produced, so compilation, exact reconciliation, and 10,000-run
simulation are not applicable. Because Gate 5 does not qualify, production
integration, the original-20M/portfolio gate, release WASM, web tests, and the
final full pipeline are not run.

## Durable boundary

A future plan may reuse the exact V2 path and its raw oracle. The next useful
structural target is final-depth projected successor accumulation: reduce or
factor the 638,365 direct terminal branches while retaining every proof- and
future-visible distinction. Reclassifying that work as free is not an
acceptable path to qualification.
