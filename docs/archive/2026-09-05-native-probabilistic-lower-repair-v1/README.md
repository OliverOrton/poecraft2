## Native scope and expectation proof

The measured frame fixes the session/data/base/item level/goals/prices/caller
programs and the exact fractured suppression modifier 28 (goal mask 16).
It covers current rarity, exact satisfied-goal mask and both occupancies,
arbitrary remaining ordinary modifier identities and exclusions, and all
Eldritch tiers/sides. Generic influence, active metamods, additional fractures,
veiled modifiers and item flags are outside the frame. Native pool inputs do
not depend on Eldritch tier; both side effects are covered. The old support
view still requires its exact phase. The existing caller excludes Imprint;
enabling it or supplying an authored restore program refuses this new view.

Overlap-aware native minimum-affix logic establishes impossible cells; other
uncertain cells remain optimistic. A native single-mod add can gain only the
goal mask of an actual modifier. Rarity legality prevents Transmute in this
fractured frame. Destructive actions use current progress and retain the exact
fracture; renewal still optimistically relaxes early stopping/junk occupancy.

For each conditional draw, let N be full satisfying weight, B other weight,
and D an upper bound on other weight removed by all possible blockers. Then
the witness uses `N / (N + max(0, B-D))` as a probability upper. Removing target
weight cannot invalidate it: the numerator retains N while the denominator's
other mass has a proved lower. The strongest per-side exclusion effects may
overlap and are deliberately overcounted. Native integer totals, target event,
side, guaranteed/natural pool and blocker assumptions remain in the payload.
Conditional draw bounds are unioned; single-goal marginals are never multiplied.

An exact successor-mask event entails each new goal, giving a conservative
capacity from the minimum of their upper bounds. Capacities round upward to
the 2^-24 grid. Unit mass is allocated to the cheapest frozen-value events,
with occupancy choices kept optimistic and all remaining mass retained.
The resulting expectation is below every distribution obeying those capacities.
All rows and choices are rebuilt for the final frozen vector and the existing
quotient checks the simultaneous inequalities with exact binary arithmetic.
These are value-specific relaxed relations, not all-vector exact native kernels.

Complete priced primitive coverage is checked before identical relations are
grouped by cheapest cost. Cheap independent price floors are tried first;
unsupported paid exits use zero continuation. Exact fresh Restart continuation
is 36.11443172876641 from the existing preparation owner. No unverified new
candidate supplies that boundary. Supported programs telescope primitive
inequalities to the goal or first independent boundary; checkpoint restore
needs memory absent from this frame and is refused under any widened scope.
