# Certified Root-Action Feasibility Report

**Status: final negative result and boundary record.**

## Decision

Gate 1 rejected the current mechanism. Gates 2 through 4 were not entered.

The measurement separated a complete admitted root operator envelope into
exact executable first-action classes before attempting the first ordinary
broad row. It paired each class with an isolated admissible descriptor-cover
lower and watched for a certified executable incumbent upper. The positive
constructive-certificate oracle reported strict separation, but all four hard
cases reported:

```text
root envelope complete
first-action projection complete
class lowers complete
finite executable root upper absent
certificate absent
```

Each hard case then refused at `max_discovered_states` while materializing its
first Chaos row. The existing constructive state certificate cannot repair
this ordering: it requires a complete retained selected row and finite
constructive uppers for every non-self successor. The row that would enable
the proof is the row the solver cannot materialize.

This corrects the outside estimate that root-action certification was already
mostly built. The proof comparison primitive exists, but the hard-case
pre-expansion upper does not. A durable result type, early termination, and
product presentation would currently expose only an unavailable result.

## Frozen Semantics

A root action is the complete first executable primitive craft request.
Planner programs sharing that request belong to one class. For class `A`,
`L_A` is the minimum admissible operator lower and `U_A` is the minimum
certified executable policy upper. Certification requires one finite `U_A`
to be strictly below every competing class lower after comparison tolerance.
Missing scope, prices, projections, lowers, ties, or overlapping intervals
block the claim.

The shadow lower used the current descriptor-cover proof shape without
initializing the production clean-carrier probability table. It grants an
operator every goal slot any constituent could reach and charges only
guaranteed first primitives, so it remains lower-only. This substitution was
needed after the first diagnostic implementation invoked the expensive
production cache and crashed the smoke process. It does not affect the Gate 1
decision: no hard case supplied any upper to compare against any lower.

## Consequence

The next root-action attempt must begin with a materially new proof-producing
capability, not public integration:

1. obtain a certified executable upper for at least one root-action class
   before broad-row materialization; then
2. strengthen competing class lowers enough to separate that upper.

The archived fixed-policy renewal research is relevant evidence but not a
ready solution: it produced finite pre-expansion candidates only with
substantial diagnostic work, exceeded the product work cap on both three-mod
cases, and its cheap lower left Chaos at `1`. A future plan needs a genuinely
cheaper exact action-class upper or a new admissible action-local lower, with a
frozen hard-case falsification gate.
