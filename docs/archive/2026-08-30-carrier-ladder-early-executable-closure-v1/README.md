## Objective

Make the existing near-optimal PDR direct core policy a proper independently
evaluated executable candidate materially earlier than terminal strict exact
closure, using the existing carrier-ladder, continuation, compiler, evaluator,
and strict-refinement authorities.

This was not fragment or retention/capacity work, a new planner, a permanent
item/base library, a broad whole-policy retry, or a fixed scheduling window.

## Diagnosis

The bounded off-policy sample did not name a missing action, retry basin, or
terminal-only distinction. It named ordinary magic, clean, one-goal carrier
states already inside the closed exact coarse solve. The core policy contains
7,212 selected nonterminal states and 28 distinct actions, but ordinary direct
compilation owned only its root-policy-reachable quotient subset. Strict lift
worked because it reintroduced the already solved expanded coarse
representatives before exact evaluation.

The missing contract was therefore assertion-domain ownership, not another
ladder, planner, fragment library, action-catalogue entry, or global retry.

## Retained Change

Direct assertion may now request a closed coarse certification domain only
when the source result is exact, all three coarse closure claims are true, no
state/resource cap stopped it, and no structured refined route supersedes it.
In that scope the compiler:

- adds every expanded, self-representative, nonterminal row with a finite
  selected policy;
- maps all physical behavioral members through those representatives;
- excludes semantic goals and the gated retry basin from policy routing;
- proves the represented physical domain and keeps every unmatched path on
  the existing fail-closed terminal;
- compiles certification and paired product artifacts with identical topology;
  and
- refuses stale reachable-only cached artifacts for a closed-domain request.

The quotient route vocabulary now observes the presence of each fractured
metamod family through native modifier-count predicates. Bounded telemetry
records closed-domain working/added/route counts, fail-closed default sources,
and the highest-mass off-policy exact state classes. No publication,
incumbent, proof, cancellation, cap, mechanic, action, or frontend authority
moved.

A hardened rerun exposed one bookkeeping defect before qualification:
non-representative quotient goal members deliberately have sparse Bellman goal
bits. The compiler now validates semantic goal truth against the representative
and excludes physical goal members from routing without mutating Bellman
bookkeeping. The focused fractured-goal regression owns this case.
