# Solver Goal Realignment V1

This corpus owns the frozen acceptance cases for the active
[Solver Goal Realignment And End-To-End Capability Recovery](../../../docs/active/2026-08-09-solver-goal-realignment/plan.md)
milestone.

The primary case is an empty rare item-level-86 Conquest Lamellar under the
checked-in Allflame economy plus an explicit five-chaos `base` override. It
requires four natural T1 modifiers and uses Calculator's goal-relevant action
envelope with `goal_progress_gated_reforges`. The historical Mirage regression
fixture is unchanged.

The focused Vaal Regalia case starts with a satisfied suffix goal and existing
Exarch dominance. Its open, naturally rollable prefix target, pinned Allflame
snapshot, and disclosed synthetic `eldritch_exalt` price override force the
carrier-local automatic option. The contract records both the 3.59-chaos
snapshot quote and the 0.001-chaos fixture value; this is a forced-winner gate,
not a claim about live optimality. The real `eldritch_exalt` primitive remains
dependency-only and must appear in the compiled strategy, which is
exact-evaluated and verified for 10,000 runs.

The Vaal Regalia Influence case asks for a Warlord-only T1 body-armour
family on an uninfluenced empty rare. It uses the live pinned Warlord Exalt
quote with no action-price override, so product relevance, canonical currency
identity, row/Q completion, selection, compilation, exact evaluation, and
10,000 Simulator runs are exercised by a naturally necessary route.

The tracked Runic Gauntlets case promotes the former build-only four-of-five
partial-state control into the current corpus. It preserves four natural T1
affixes, seeks a fifth Cold Resistance goal, uses the pinned Allflame snapshot
plus an explicit one-chaos base input, and is owned by
`five-mod-manifest.json` with a ten-minute watchdog. Exact is
preferred; a bounded result qualifies only when it still publishes, compiles,
independently evaluates, and completes 10,000 Simulator runs with honest open
obligations and bounds. Its machine-enforced bounded-policy contract requires
a named resource stop, a strict lower/upper gap, nonzero unresolved work, an
evaluated upper bound, and the cheapest independently evaluated publication
candidate. Exact closure remains the stronger accepted path.

`gate6-manifest.json` adds two focused current-product controls without
changing the preserved 49-case reliability corpus: one starts with a real
crafted Prefixes Cannot Be Changed metamod, and one starts with a full junk
prefix side plus a useful Fire Resistance suffix that must be preserved while
Cold Resistance is completed. Both demand exact compiled evaluation and
10,000 Simulator runs.

The primary Conquest Lamellar case is successful only when native and release
WASM both close exactly within five minutes, publish the same-semantics
independently evaluated strategy, and complete the milestone's required
10,000-run verification. A bounded or cap-stopped primary policy remains
useful evidence but does not satisfy that case. The separate five-mod manifest
owns its explicitly bounded ten-minute acceptance contract.
