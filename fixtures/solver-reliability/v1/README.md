# Cross-base compiled-strategy reliability corpus v1

This deterministic portfolio is generated by the existing natural-T1
generator and consumed by the existing native benchmark and staged runner. It
does not replace or mutate `fixtures/solver-natural-t1/v1`.

The portfolio contains:

- 49 cases: 27 one-goal item-class smokes, six two-goal breadth cases,
  seven three-/four-goal representatives, two dense deep diagnostics, five
  authored special starts, and two selected verification cases;
- two-, three-, and four-goal prefix, suffix, and mixed-side shapes;
- empty rare, crafted, fractured, influenced, Eldritch, and Veiled starts;
- dense, low-probability deep diagnostics under the portfolio's pinned
  20,000,000 reforge-work boundary;
- exact Calculator evaluation and a Simulator smoke for every returned
  policy, with exact cost reconciliation; and
- two selected 10,000-run verification cases.

Generate it from the repository root:

```powershell
$env:PYTHONPATH = 'tools/ingest;bindings/python'
py -3 tools/ingest/generate_natural_t1_corpus.py fixtures/solver-reliability/v1/generator-config.json
```

The generated economy identity uses the snapshot's declared content hash and
source cutoff, matching the shared native/WASM corpus loader contract.
`benchmark-stages.json` preserves the
smoke -> breadth -> representative -> deep -> selected-verification funnel.
Every stage enables exact evaluation, simulation for each compiled policy,
and goal-progress-gated reforges. The portfolio pins a 900-second case
watchdog, 1,000 expanded states, 20,000,000 reforge-work units, 1 GiB selected
solver-owned memory, and a 20-second stress-corpus cooperative worker-slice
ceiling. These are corpus bounds, not changes to product solver defaults.

Exact, bounded, capped-with-policy, capped-without-policy, unsupported,
compilation-failed, evaluation-failed, simulation-failed, and mismatch states
remain separate in native and WASM reports. Reliability expectations accept
only classified outcomes; any returned policy must compile, exact-reconcile,
and simulate without an off-policy action. The two verification-tier policies
run 10,000 simulations each.
